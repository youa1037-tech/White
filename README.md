# 탄환은 백야를 꿰뚫는다

**The Bullet Pierces the White Night**

페르소나 5 더 로열 3학기, 아케치 고로의 시점으로 2월 1일 저녁부터 3월 20일까지를 따라가는 인터랙티브 텍스트 픽션입니다. 플레이 시간은 45~60분이고, 엔딩은 True End 하나와 Bad End 둘입니다.

## 플레이

`index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 배포하면 됩니다.

### GitHub Pages로 올리기

1. 이 폴더의 파일을 저장소 루트에 올립니다.
2. 저장소의 **Settings → Pages**에서 **Branch**를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소에서 열립니다.

`.nojekyll`은 GitHub Pages가 파일을 그대로 내보내도록 두는 빈 파일입니다.

## 흐름

장 구분 없이 날짜가 바뀌며 이어집니다.

- 2월 1일 저녁, 오다이바
- 2월 1일 밤, 키치죠지
- 2월 2일 밤, 르블랑
- 2월 3일, 오다이바 팰리스
- 3월 20일

타이틀의 「이어하기」는 마지막으로 도달한 날짜의 처음부터 다시 시작합니다.

## 조작

- 화면을 누르거나 Enter, Space로 다음 문장
- ✧ 표시 단어를 누르면 관찰
- 회색 문장은 「말을 삼킨다」를 누르고 있거나 Backspace로 지운다
- 오른쪽 위 아이콘: 설정, 관측 기록

진행 기록은 브라우저의 localStorage에 저장됩니다. 다른 기기나 브라우저와는 공유되지 않습니다.
